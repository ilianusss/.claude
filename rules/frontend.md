# UI work

- After a UI change, look at the result in a browser at mobile and desktop widths when you have a browser tool.
- Be picky about what you see: alignment, spacing, overflow, truncation, focus and hover states, dark mode. If something you touched looks off, fix it before calling the task done.
- Reuse the project's components and design tokens before writing new ones. Tailwind arbitrary values only when no token fits.
- Semantic HTML first. Everything clickable works with the keyboard and shows its focus.
